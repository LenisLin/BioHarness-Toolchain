# Knowledge Registry

This directory is the repo-authoritative agent-facing knowledge entry for current BioHarness Layer 1 and Layer 2 spatial transcriptomics selection.

`knowledge_registry/` organizes compact knowledge artifacts for problem routing and method selection. It was migrated from the current NAS `formal/` result presentation, but this repo path is now the ordinary agent-facing entry.

The source/evidence artifacts remain listed in `SOURCES.md`. They are not replaced or rewritten by this registry.

Layer 3/4 engineering workspaces are outside the scope of this Layer 1/2 knowledge registry.

## Entries

- `SOURCES.md`: file-level source map for the current knowledge registry.
- `LAYER_BOUNDARY.md`: layer boundary and current-state note.
- `layer1/`: Layer 1 problem-routing entry point.
- `layer2/`: Layer 2 method-selection standard and topic files.
- `protocols/layer1_2_selection/`: agent protocol and machine-readable selection policy.
